### Core Data Interfaces (exact — put in src/lib/types.ts)
```ts
export interface FoodItem {
  id: string;
  name: string;
  caloriesPerServing: number;
  protein: number;
  carbs: number;
  fat: number;
  fiber: number;
  sugars: number;
  scaleType: 'count' | 'scale';
  unit?: 'g' | 'oz';           // only for scale items
  servingDesc: string;
  categories: string[];
  isRecipe: boolean;
  recipeComponents?: { foodId: string; quantity: number }[];
  lastUsed: string;
  timesUsed: number;
}

export interface LoggedFood {
  id: string;
  foodId: string;
  quantity: number;
  note?: string;
  overriddenComponents?: { foodId: string; quantity: number }[]; // for recipe instances
}

export interface DailyLog {
  date: string; // YYYY-MM-DD
  goalTemplateId: string;
  foods: LoggedFood[];
  burnedCalories: number;
  note: string;
}

export interface GoalTemplate {
  id: string;
  name: string;
  calories: number;
  protein: number;
  carbs: number;
  fat: number;
  fiber: number;
  sugars: number;
}

export interface Settings {
  goalTemplates: GoalTemplate[];
  defaultTemplateId: string;
  theme: 'dark' | 'light';
  accentColor: string;
}
```

### Exact UI Rules (must implement precisely)

**Bottom Navigation (fixed, 4 tabs)**
- Daily (default on launch)
- Library
- Stats
- Settings

Active tab uses dark red accent. Tapping current tab does nothing (or scrolls to top).

**Daily Tab**
- Sticky header with ← date → + calendar picker button
- Prominent "Goals vs Remaining" grid (6 metrics)
- Large Net Calories display
- Logged foods list (tap opens edit sheet)
- Burned calories row with edit
- Collapsible daily note
- **View Mode / Edit Day toggle** at top (default View Mode = read-only). When Edit Day is on, all editing is unlocked and auto-saves.
- Large + Add Food FAB/button that opens Food Picker bottom sheet

**Quantity Input Rules (critical)**
- If scaleType === 'count': big + and – buttons, integer only, large centered number
- If scaleType === 'scale': number input (step 0.01, up to 2 decimals) + unit label clearly shown next to the input (the unit saved with the FoodItem: 'g' or 'oz')
- Always show servingDesc context
- Optional note field
- Big primary button: "Add to [current date]"
- Prominent Cancel / X that returns to previous screen without adding

**Recipe Flow (exact)**
- Recipes appear in Food Picker with 🍱 badge
- Selecting a recipe → immediate preview sheet showing standard quantities + two big buttons at bottom:
  - **Add** (uses default quantities, adds to day instantly)
  - **Edit** (goes to customization screen)
- **Edit / Customize screen**:
  - List of all components with editable quantity fields (respecting each component's scaleType)
  - Live-updating total macros for the customized meal
  - Bottom actions: **Add to day** (saves the overridden quantities for *this instance only*) | **Cancel** (returns to preview without changes)
- The override is stored in the LoggedFood record so future uses of the same recipe start clean from the master definition.
- Every sheet/modal has clear Cancel / X / Back — user can never get stuck.

**Library Tab**
- Opens in alphabetical order with sticky letter headers (A, B, C… only letters that have items — no empty letter sections)
- Top segmented control / tabs: **Items** | **Categories** | **Recipes**
- Live search bar at the top of every view (scoped to current segment)
- **Edit** button in header enters multi-select checkbox mode for bulk delete (action bar appears with "Delete Selected")
- FAB or header buttons: **+ New Food** and **Create Recipe**
- Create Recipe flow: search/add multiple foods with quantities → live totals → name it → save as new FoodItem (isRecipe=true, stores recipeComponents)

**Stats Tab**
- Default period: **This Week**
- Segmented control: This Week | This Month | Custom (with date pickers when Custom)
- Quick prev/next arrows to shift period
- Summary cards showing:
  - Actual totals for logged days in the period
  - **Proportional goals** = (number of days actually logged in this period) × daily goal values
- View toggle: Table | Charts
- Table: sortable table of each logged day (tap row → load that date in Daily tab)
- Charts (Recharts, dark theme, clean):
  - Line chart: Net Calories trend
  - Stacked/grouped bar: daily macro breakdown
  - Click chart point → loads that day in Daily tab

**Settings Tab**
- Goals & Templates management (list, edit, delete, set default, create new)
- Data section (big & prominent):
  - Import Food Library (.json / .csv / .xlsx) with preview + Replace/Merge options
  - One-click "Load My Food Library (87 items)" seed button
  - Export Everything (full JSON backup download)
  - Factory Reset (red, double confirm + warning)
- Appearance: Dark/Light toggle + accent color swatches (default very dark red)
- About section with app name and credits

**First Launch Behavior**
- Minimal. No onboarding carousel or tutorial.
- If library is empty: show friendly empty state in Library tab + prominent "Load My Food Library (87 items)" button + import file picker.
- Daily tab shows empty state with "Add your first food" CTA.
- Everything is self-explanatory via clear labels, icons, and empty states.

- Clean success/error toasts

- Dark theme with very dark red (#8B0000) accents by default

- TypeScript strict mode, clean readable code, good component organization
